# Project rules
- Keep exhibitor records in the centralized data catalogue and brochure sections in its category map; align their classifications when either changes to prevent filter/index divergence.
- Derive brochure page counts and navigation targets from the constructed slide sequence so removing pages cannot leave stale links.
- Render homepage partners from the centralized exhibitor catalogue; partner-only records stay outside the recruiting exhibitor list to avoid implying recruiting attendance.
- Keep programme events in a typed data module shared with rule tests so schedules and rooms can be validated independently of presentation.
